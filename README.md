# Muhammad Mujasam — Professional Portfolio Website

Modern, responsive personal portfolio website for **Muhammad Mujasam**, a Flutter & Mobile App Developer with experience in cross-platform mobile engineering, Firebase, REST APIs, and database management.

🔗 **Live Website**: [https://buster90.github.io/muhammadmujsam/](https://buster90.github.io/muhammadmujsam/) *(or custom domain / repository Pages URL)*

---

## 🚀 Key Features

- **Developer Aesthetic**: Minimal, modern developer theme with a deep charcoal dark theme default and smooth light mode toggle.
- **Hero & Interactive Smartphone Mockup**: Interactive phone frame featuring live toggle between **Pusher Tasks** and **Ride Tracker** (with real-time simulated GPS tracking).
- **Technical Skills**: Filterable skill grid categorized into Mobile Development, Backend & Database, Integration & APIs, Computer Science, and SEO.
- **Featured Projects**:
  - **Pusher Task Management App**: Lightweight productivity app built with Flutter.
  - **Ride Sharing Mobile App**: Cross-platform FYP honored with the **Transportation Innovation Award — 2023**.
- **Academic Foundations**: Computer Vision (Numeric Recognition 0–9), Cisco Campus Network Architecture, and SQL DBMS Library System.
- **Career & Education**: Vertical timeline for Vie Apps Studio, M2Logix, and Superior Tech Solutions, alongside formal education at Lahore Garrison University.
- **Executive Resume**: In-app modal with dedicated print-to-PDF styles for recruiters and hiring managers.
- **Contact Form**: Real-time validation, 1-click clipboard copy for phone & email, and direct mailto fallback.
